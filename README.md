# 🍽️ Restaurant Table Reservation App

A mobile-first UI/UX design for a simple and efficient table reservation system.

## 🎯 Objective
To make restaurant booking easy, fast, and user-friendly.

## 💡 Features
- Table size selection  
- Date & time booking  
- Simple booking form  
- Confirmation screen
